PWM — Motor Speed / Servo
from machine import PWM, Pin

motor = PWM(Pin(0))   # MTR0_PWM
motor.freq(1000)      # Hz — 1000 for motors

# duty_u16: 0 = off, 65535 = full
motor.duty_u16(0)       # stop
motor.duty_u16(32768)   # 50%
motor.duty_u16(65535)   # full speed
ADC — Analog Input
from machine import ADC

# Channel 0 = GP26  (ADC_0)
# Channel 1 = GP27  (ADC_1)
# Channel 2 = GP28  (ADC_2)
sensor = ADC(0)

raw = sensor.read_u16()     # 0 – 65535
volts = raw * 3.3 / 65535  # convert to V
print(volts)

Motor Control Pattern
from machine import Pin, PWM

pwm0  = PWM(Pin(0));  pwm0.freq(1000)
ina0  = Pin(8,  Pin.OUT)
inb0  = Pin(10, Pin.OUT)

def forward(speed):        # speed: 0–65535
    ina0.value(1); inb0.value(0)
    pwm0.duty_u16(speed)

def backward(speed):
    ina0.value(0); inb0.value(1)
    pwm0.duty_u16(speed)

def stop():
    ina0.value(0); inb0.value(0)
    pwm0.duty_u16(0)

Ohm's Law
V = I × R
VoltageV (volts)
CurrentI (amps)
ResistanceR (ohms Ω)
Rearranged: I = V / R   R = V / I
Power
P = V × I
PowerP (watts)
Also: P = I² × R   P = V² / R
Example: 5 V motor drawing 500 mA = 2.5 W
Pico 2W GPIO Limits
Logic level3.3 V
Max per pin~4 mA direct
Max all pins total50 mA
ADC resolution12-bit (0–65535 u16)
ADC reference3.3 V
Motors draw hundreds of mA — always use a motor driver board. Never connect a motor directly to a GPIO pin.
LED Resistor Calculator
R = (Vs − Vf) / I
Supply voltage Vs3.3 V (Pico GPIO)
LED forward voltage Vf~2.0 V (red/yellow)
LED forward voltage Vf~3.0 V (blue/white)
Target current I10 mA = 0.010 A
Red LED: (3.3 − 2.0) / 0.010 = 130 Ω → use 150 Ω
Blue LED: (3.3 − 3.0) / 0.010 = 30 Ω → use 33 Ω
