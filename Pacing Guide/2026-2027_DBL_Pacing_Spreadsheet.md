# 2026–2027 Design and Build Lab — Pacing Spreadsheet

**School year:** Aug 31, 2026 – Jun 11, 2027  
**Grades:** 9–12 (mixed)  
**Instructional weeks:** ~38 (≈170 days)  
**Note:** Full-year course; all students follow the same project sequence. CIP code shared with HS AER — EDP, CAD, manufacturing, and electronics/programming content satisfy the same standards.

## Project Sequence
| # | Project | Format | Primary Skills |
|---|---------|--------|---------------|
| P1 | 3D Printed Fidget Spinner | Individual | CAD, 3D printing, assembly |
| P2 | LED Sign / Wall Art | Groups (2–3) | CNC/plasma, basic circuits, soldering |
| P3 | Custom Acrylic Christmas Ornament | Individual | CNC/laser engraving, finishing |
| P4 | Silicone Molds | Individual | CAD, 3D printing, casting process |
| P5 | Automated Plant Watering | Groups (2–3) | Arduino, sensors, relay, enclosure design |
| P6 | Capstone | Groups (2–3) | Student-driven, all skills |
