Get Ready

What you'll need:

Wiring Reminder 
OSOYOO Sensor → Pico GPIO
S0 (leftmost)  → GP6
S1             → GP7
S2 (center)    → GP8
S3             → GP9
S4 (rightmost) → GP10

(Match the wiring from Activity 4.10)

Add this starter code to the top of your file. Both functions are used throughout all four parts — define them once and keep them.

starter code — add to top of file
from machine import Pin
import time
import motor

# IR sensor pins (left to right: S0–S4)
ir_pins = [Pin(p, Pin.IN) for p in [6, 7, 8, 9, 10]]

def read_sensors():
    """Read all 5 IR sensors. Returns list of ints: 0=line, 1=no line."""
    return [p.value() for p in ir_pins]

def compute_error(sensors):
    """Weighted position error. Returns float or None if no sensors see line."""
    weights = [-2, -1, 0, 1, 2]
    total_weight = 0
    count = 0
    for i in range(5):
        detected = 1 - sensors[i]   # invert: 0→line
        total_weight += weights[i] * detected
        count += detected
    if count == 0:
        return None
    return total_weight / count
✅

Part 2: P Control
~15 min

Goal: Implement proportional control to follow the line. The correction is directly proportional to the error — bigger error, bigger correction.

1
Add the P control loop below your starter functions

Start with Kp = 25 and base_speed = 40. Place the robot on the line, then run.

part2_p_control.py
Kp = 25          # starting value — tune this
base_speed = 40  # % duty cycle

prev_error = 0

while True:
    s = read_sensors()
    error = compute_error(s)

    if error is None:
        motor.drive(0, 0)   # lost the line — stop
        continue

    correction = Kp * error
    left  = base_speed + correction
    right = base_speed - correction
    motor.drive(left, right)
    time.sleep(0.01)

Part 3: PD Control
~15 min

Goal: Add the derivative term to reduce oscillation. The D term reacts to how fast the error is changing — it acts like a brake when the robot is swinging back toward center too aggressively.

1
Update your control loop with the derivative term

Replace your Part 2 loop with this version. Start with your Kp from Part 2 and Kd = 0.4 × Kp (so if Kp = 25, start Kd = 10).

part3_pd_control.py
Kp = 25          # your tuned value from Part 2
Kd = 10          # start at ~0.4 × Kp
base_speed = 40
prev_error = 0

while True:
    s = read_sensors()
    error = compute_error(s)

    if error is None:
        motor.drive(0, 0)
        prev_error = 0
        continue

    correction = Kp * error + Kd * (error - prev_error)
    prev_error = error

    left  = base_speed + correction
    right = base_speed - correction
    motor.drive(left, right)
    time.sleep(0.01)
2
Tune Kd using this table

Keep Kp at your Part 2 value. Only adjust Kd.

ObservationAction
Oscillation still presentIncrease Kd by 5
Robot responds sluggishly to curvesDecrease Kd by 5
Smooth, quick trackingDone!

💡
PD is usually enough

PD control handles most line-following courses well. You may not need the I term unless the robot has a persistent drift to one side even on a perfectly straight line — that's the sign of a systematic error the P term alone can't correct.

🔴 Level 3 Add the I Term

Implement the full PID controller by adding the integral term. Add the lines below inside your loop, just before computing correction. Use very small Ki — start at 0.05.

add inside the loop
Ki = 0.05        # keep very small!
integral = 0
MAX_INTEGRAL = 30

# inside the loop, before computing correction:
integral += error
integral = max(-MAX_INTEGRAL, min(MAX_INTEGRAL, integral))
correction = Kp * error + Kd * (error - prev_error) + Ki * integral

Does the I term help on your course? Explain when the I term would and would not be useful.

🔴 Level 4 Lost-Line Recovery

Instead of stopping when compute_error() returns None, implement a recovery behavior:

  • If the robot was last turning left (negative error), spin left to search for the line.
  • If it was last turning right (positive error), spin right.
  • After 0.5 seconds of searching, stop.

Add this recovery logic to your code and test it by lifting the robot off the line, then setting it back down.
