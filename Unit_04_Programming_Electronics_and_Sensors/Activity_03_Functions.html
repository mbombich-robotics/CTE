Activity 4.3 — SOS with Functions

Build from the ground up: one function, then functions that call functions, then a complete SOS loop. Raise your hand at each checkpoint before moving on.

~30 minutes Lesson 4.3
1
Your First Function
~10 min

Start a new file. You're going to replace the raw blink code with a function that accepts the blink duration as an argument.

1
Type the setup code at the top

Same imports and LED setup as before — functions go below this.

main.py — start here
from machine import Pin
import time

led = Pin("LED", Pin.OUT)
2
Define the blink function below the setup

The parameter duration_ms is a placeholder. When you call blink(100), MicroPython substitutes 100 wherever duration_ms appears inside the function.

blink function
def blink(duration_ms):
    led.value(1)
    time.sleep_ms(duration_ms)
    led.value(0)
    time.sleep_ms(100)    # fixed gap between blinks
3
Call the function three times with different durations

Add a while True: loop at the bottom. Call blink() with three different values separated by a 1-second pause. Observe the different blink lengths on the LED.

main loop — add below your function
while True:
    blink(100)              # short
    time.sleep_ms(1000)
    blink(400)              # medium
    time.sleep_ms(1000)
    blink(1000)             # long
    time.sleep_ms(1000)
💡
One function, three behaviors

The same four lines of code — LED on, wait, LED off, wait — run every time, but the LED-on duration changes based on what you pass in. That's the point of a parameter. Change timing in one place (the function definition), and every call automatically uses the new value.

✋
Checkpoint 1

Your LED cycles through three clearly different blink lengths (short / medium / long). Raise your hand — show the teacher before moving on.

2
Dot & Dash
~10 min

Now build two functions on top of blink() — one for a Morse dot and one for a dash. No raw numbers in your main loop; all timing lives in the functions.

📡
Morse code timing

Standard Morse ratio: a dash is three times longer than a dot. Using 100ms for a dot and 300ms for a dash keeps the gap between blinks at 100ms (already handled inside blink()). A letter gap is an extra 300ms off after the last blink of a letter.

1
Remove the while True from Part 1 — add dot() and dash() above it

Keep your blink(duration_ms) function. Add the two new functions below it.

add after blink()
def dot():
    blink(100)

def dash():
    blink(300)
2
Test dot() and dash() in a new while True loop

Send three dots (S), wait 300ms for a letter gap, then three dashes (O), then wait again. You should see the clear contrast between dot and dash.

test loop
while True:
    dot(); dot(); dot()        # S
    time.sleep_ms(300)          # letter gap
    dash(); dash(); dash()      # O
    time.sleep_ms(1000)         # word gap before repeat
✋
Checkpoint 2

You can clearly see three short blinks followed by three long blinks, repeating. Raise your hand to confirm with the teacher.

3
Complete SOS
~10 min

Add one more function — sos() — that calls dot() and dash() in the Morse pattern for S-O-S. Your while True loop becomes a single clean line.

1
Add the sos() function below dot() and dash()
sos function
def sos():
    dot(); dot(); dot()        # S
    time.sleep_ms(300)
    dash(); dash(); dash()      # O
    time.sleep_ms(300)
    dot(); dot(); dot()        # S
    time.sleep_ms(1000)         # pause before next SOS
2
Replace the while True loop with a single sos() call

Your entire main loop is now two lines.

main loop — final
while True:
    sos()
🔍
Full file structure, top to bottom

Imports → LED setup → blink(duration_ms) → dot() → dash() → sos() → while True: sos(). Each level builds on the one above it. Want to change the dash length? Edit one line in dash() — the whole SOS automatically uses the new timing.

✋
Checkpoint 3 — show the teacher

Your Pico is transmitting a clean, repeating SOS pattern. Show the teacher your code and the running light before moving to challenges.

Challenges
finish early?

Start from your working SOS program. Each challenge adds a new function or new capability — you're not rewriting what you built, you're extending it.

C1 Gap Functions

Right now the letter gap and word gap are raw time.sleep_ms() calls spread through your code. Replace them with named functions:

  • def letter_gap(): — 300ms pause
  • def word_gap(): — 1000ms pause

Update sos() to call letter_gap() and word_gap() instead of the raw sleep values. Now try changing the gap timing — one edit, everywhere it's used.

C2 Encode More Letters

Morse code for reference: H = · · · ·   I = · ·   E = ·   L = · — · ·

Write def letter_h(): and def letter_i():. Then write a new loop that sends "HI" followed by a word gap, repeating. Each letter function ends with a letter_gap() call.

If you finish HI, add "HELP" — you'll need to look up M, E, L, P in the Morse alphabet.

C3 Repeat Function

Write a function that accepts a count and calls sos() that many times:

def repeat_sos(n):
    for i in range(n):
        sos()

Call it with repeat_sos(3) in your while True. Then try repeat_sos(5). Notice that n is a parameter — range(n) uses it just like duration_ms was used inside blink().

C4 Emergency Beacon

Write def emergency_beacon(): with no parameters. It signals SOS exactly 5 times with a 3-second gap between repetitions, then stops. No while True — after 5 signals, the LED goes dark.

Hints: use range(5) inside the function. After the loop, add led.value(0) to ensure the LED is off. Call it once from your main code — not in a loop.

This is how a real emergency beacon works — it broadcasts a fixed number of times to conserve battery, then waits for a reset.
