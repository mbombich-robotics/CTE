What Is PWM?

A digital output pin has two states: fully on (3.3 V) or fully off (0 V). You can't tell it "be at half voltage" — the hardware doesn't work that way.

Pulse Width Modulation is a workaround: switch the pin on and off thousands of times per second. The LED (or motor) can't react fast enough to follow each switch — it just averages the power. More time on = brighter. Less time on = dimmer.

The key insight

The voltage never changes — it's always 3.3 V when on, 0 V when off. What changes is how much of the time it spends on. That fraction of on-time is called the duty cycle.

Two Controls: Duty Cycle & Frequency

A PWM signal has exactly two parameters. Each controls something different.

Duty Cycle — controls power

The percentage of each cycle the signal is HIGH. This is what you change to control brightness or speed.

  • 0% — always off
  • 50% — half power
  • 100% — always on, full power

In MicroPython: duty_u16() accepts 0–65 535
50% = duty_u16(32768)
75% = duty_u16(49151)

Frequency — controls smoothness

How many complete on/off cycles happen per second (Hz). The frequency doesn't change the power level — it changes how smooth or rough the effect feels.

  • Too low (<50 Hz) — visible flicker on LEDs; audible whine from motors
  • 1 000 Hz (1 kHz) — invisible flicker; good for LEDs and most motors
  • Too high (>50 kHz) — motor drivers may not switch fast enough

In MicroPython: freq(1000) — set once and leave it.

Rule of thumb

Set freq(1000) at the start and don't change it. Change only duty_u16() to control brightness or speed. You adjust duty cycle constantly; you rarely touch frequency.

PWM in MicroPython

Setup and basic use

PWM is a separate class you import alongside Pin. You wrap a GPIO pin in a PWM object, set the frequency once, then control brightness with duty_u16().

from machine import Pin, PWM import time # GP15 — use a GPIO pin, not "LED" led = PWM(Pin(15)) led.freq(1000) # 1 kHz — set once led.duty_u16(0) # off time.sleep(1) led.duty_u16(16384) # 25% time.sleep(1) led.duty_u16(32768) # 50% time.sleep(1) led.duty_u16(65535) # 100%

The set_brightness function

Raw numbers like 49151 are hard to reason about. Wrap the conversion in a function that speaks in percentages:

def set_brightness(percent): duty = int(percent / 100 * 65535) led.duty_u16(duty) # Now your code reads like English set_brightness(0) # off set_brightness(25) # quarter power set_brightness(100) # full

Why int()?

percent / 100 * 65535 produces a float like 32767.5. duty_u16() requires a whole number — it raises a TypeError if you pass a float. int() truncates to the nearest integer.

From LED to Motors

You're not learning PWM just to dim LEDs. PWM is how motors are speed-controlled — the exact same concept, applied to a much larger current through the motor driver chip.

LED now

  • GPIO pin → 330Ω resistor → LED
  • Current: ~10 mA
  • Result: variable brightness
  • Duty 0% = off, 100% = full bright
set_brightness(50) # 50% bright

Motors in L5.5

  • GPIO pin → VNH5019 motor driver → motor
  • Current: up to 12 A (driver handles it)
  • Result: variable speed
  • Duty 0% = stopped, 100% = full speed
drive_forward(50) # 50% speed

The connection

In Lesson 4.5, drive_forward(speed) will be a function that takes 0–100 and calls duty_u16() on the motor pins — exactly the pattern you'll practice today with set_brightness(percent). The skill transfers directly.
