Activity 4.1 — Thonny Setup & First Blink

Work through each part in order. Raise your hand at each checkpoint before moving on.

~35 minutes Lesson 4.1
1
Thonny Setup
~10 min

Thonny is the app you use to write and run MicroPython on the Pico 2W. Follow these steps the first time you use a new computer.

1
Download & install Thonny

Go to thonny.org and download the Windows installer. Run it and accept all defaults.

2
Open Thonny → Tools → Options → Interpreter tab

From the dropdown at the top of that dialog, select MicroPython (Raspberry Pi Pico).

3
Install firmware (first time only)

Unplug the Pico. Hold the BOOTSEL button on the Pico while you plug the USB cable back in — hold it until the board mounts as a USB drive, then release. Back in Thonny's interpreter dialog, click Install or update MicroPython. Three dropdowns appear:

  1. Set Target device to your Pico (shows as a drive letter)
  2. Set MicroPython family to RP2
  3. Set Variant to Raspberry Pi Pico 2W

Click Install. Wait for it to finish, then click Close.

4
Click OK — check the status bar

The bottom-right corner of Thonny should now show MicroPython (Raspberry Pi Pico) and a COM port number. If it shows "Python 3" instead, repeat step 2.

5
Verify code completions are on

Go to Tools → Options → Editor tab. Confirm both of these are checked:

  • Automatically propose completions while typing
  • Automatically show documentation for completions

These are on by default. If they're unchecked, check them now. With completions on, Thonny will suggest method names as you type — e.g. type led. and a list will appear. Note that some MicroPython methods (like toggle()) won't appear in the list even though they work — use the Pico 2W Reference for those.

⚠
BOOTSEL common mistake

You must hold BOOTSEL before plugging in USB, and keep holding it until the board shows up as a drive. Plugging in first and then pressing BOOTSEL does not work.

⚠
"Access is denied" / COM port error after firmware install

Windows sometimes locks the COM port after the firmware install process. Restart the computer — this clears it every time. After rebooting, plug the Pico back in (no BOOTSEL) and reopen Thonny. If you'd rather not reboot: open Device Manager → Ports (COM & LPT) → right-click the Pico port → Disable, then Enable. Windows will likely prompt for a restart anyway.

✋
Checkpoint 1

Thonny's status bar shows MicroPython (Raspberry Pi Pico) and a COM port. Raise your hand — show the teacher before continuing.

2
Explore the REPL
~10 min

The Shell panel at the bottom of Thonny is the REPL — type a line, press Enter, and it runs immediately on the Pico. You'll see >>> when it's ready.

Type each line below into the Shell and press Enter. Don't copy the >>> — that's the prompt, not part of your code. Observe what happens before moving to the next line.

Shell — type line by line
>>> 1 + 1
2

>>> "go" * 3
'gogogo'

>>> import machine
>>> machine.freq()
150000000

>>> from machine import Pin
>>> led = Pin("LED", Pin.OUT)
>>> led.value(1)
>>> led.value(0)
💡
Why "LED" and not 25?

On the original Pico, the onboard LED was wired directly to GPIO pin 25 (a physical pin number on the chip), so code used Pin(25, Pin.OUT). On the Pico 2W, the LED is routed through the Wi-Fi chip instead, so GPIO 25 no longer reaches it. Raspberry Pi solved this by giving it the special name "LED". Using the number 25 silently does nothing — no error, no light. This trips up everyone the first time.

Checkpoint 2

You turned the onboard LED on and off from the REPL Shell. Raise your hand to confirm with the teacher.

3
Write Your First Program
~15 min

Now you'll write a real program in the editor (the top panel in Thonny). Unlike the REPL, programs run from start to finish — and with while True, they loop forever until you press Stop.

1
Click in the editor (top panel)

If the editor shows any old code, select all (Ctrl + A) and delete it.

2
Type this program exactly

Indentation matters — the four lines inside while True: must each start with 4 spaces (or one Tab). Use the copy button if you want, but typing it yourself is better practice.

main.py
from machine import Pin
import time

led = Pin("LED", Pin.OUT)  # onboard LED — use "LED", not 25

while True:
    led.value(1)       # turn LED on
    time.sleep(0.5)   # wait 0.5 seconds
    led.value(0)       # turn LED off
    time.sleep(0.5)   # wait 0.5 seconds
3
Save to the Pico as main.py

Press Ctrl + S. A dialog will ask where to save. Click Raspberry Pi Pico. Name the file main.py and click OK. Saving as main.py means it runs automatically every time the Pico powers on.

4
Press F5 (Run)

The LED should blink on and off every 0.5 seconds. Press the red Stop button to halt it.

🔍
What each line does

from machine import Pin — loads the Pin class so you can control GPIO pins.
import time — loads timing functions like sleep().
Pin("LED", Pin.OUT) — creates an output for the onboard LED.
while True: — loops forever (every robot program has this).
time.sleep(0.5) — pauses for 0.5 seconds. Use sleep_ms(500) for the same thing in milliseconds.

Your LED is blinking. Show the teacher before moving to challenges.

★
Challenges
finish early?

Start from your working blink program. Change one thing at a time — run it, observe, then move to the next. Each change should take 2–5 minutes.

C1 Speed

Change both 0.5 values to 0.1. What happens? Try 2.0. What is the relationship between the sleep value and the blink rate?

C2 Unequal On/Off

Make the LED stay on for 2 seconds but off for only 0.1 seconds. The two time.sleep() calls can have different values.

C3 Use toggle()

Replace both led.value(1) and led.value(0) with a single led.toggle(), and keep only one time.sleep(0.5). Does it work the same way?

C4 SOS Pattern

Morse code: S = · · ·   O = — — —
Short blink: 0.1s on / 0.1s off  |  Long blink: 0.4s on / 0.1s off  |  Letter gap: 0.3s off
Hint: use a for loop to repeat short and long blinks without copy-pasting.

for loop hint
for i in range(3):       # repeat 3 times (S)
    led.value(1)
    time.sleep(0.1)
    led.value(0)
    time.sleep(0.1)
time.sleep(0.3)           # letter gap
