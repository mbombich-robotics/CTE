Obstacle Detection

Use sensor readings to stop before walls, choose a turn direction, and optionally follow a wall using proportional correction.

~35 min HS AER Challenge: Wall Follow
1
Stop on Detection
8 min

The simplest useful behavior: drive forward until the center sensor reads below a threshold, then stop. This alone prevents L.E.O. from crashing into walls.

stop_on_detect.py
from leo import mux, sensor, drive_forward, stop
import time

STOP_CM = 25   # stop when closer than this

while True:
    mux.select_channel(3)            # center sensor
    center = sensor.distance_cm()

    if center is None or center > STOP_CM:
        drive_forward()
    else:
        stop()

    time.sleep_ms(50)
1
Place L.E.O. about 1 meter from a wall and run the program

It should drive forward and stop before reaching the wall. If it stops too early or too late, adjust STOP_CM.

2
Test the threshold

Try values of 15, 25, and 40. Notice how the stopping distance changes. Find a value that stops the robot cleanly without bumping.

✓
Checkpoint 1

L.E.O. drives forward and stops before touching the wall. Threshold is tuned so it stops with a consistent gap.

2
Stop & Turn
8 min

After stopping, L.E.O. needs to choose a direction. Read the left and right sensors and turn toward the more open side.

stop_and_turn.py
from leo import mux, sensor, drive_forward, stop, turn_left, turn_right
import time

STOP_CM   = 25
TURN_MS   = 400   # duration of each turn burst (ms)

while True:
    # Read all three sensors
    mux.select_channel(2)
    left   = sensor.distance_cm() or 999
    mux.select_channel(3)
    center = sensor.distance_cm() or 999
    mux.select_channel(4)
    right  = sensor.distance_cm() or 999

    if center > STOP_CM:
        drive_forward()
    elif left >= right:
        stop()
        turn_left()
        time.sleep_ms(TURN_MS)
    else:
        stop()
        turn_right()
        time.sleep_ms(TURN_MS)

    time.sleep_ms(50)
1
Run in an open space

Drive toward a wall. When it stops, check that it turns toward the side with more clearance. Use your hand to block the left or right sensor before a stop — does it change the turn direction?

2
Tune TURN_MS

If the robot over-turns (goes past the obstacle) reduce this value. If it under-turns (still facing the wall), increase it. You want roughly a 90° turn per burst.

⚠
Watch for stuck states

If L.E.O. gets cornered (all three sensors blocked), this code loops between stopping and tiny turns. Section 3 adds a recovery for this.

✓
Checkpoint 2

L.E.O. stops before walls and turns toward the more open side. You can verify the turn direction by blocking sensors by hand.

3
Full Avoidance Loop
10 min

Add a cornered recovery and tighten the logic into a clean avoidance program. This is a complete obstacle-avoiding robot.

avoidance.py
from leo import mux, sensor, drive_forward, reverse, stop, turn_left, turn_right
import time

STOP_CM   = 25
SIDE_CM   = 15   # also stop if side sensors get this close
TURN_MS   = 400
REVERSE_MS = 500

def read_sensors():
    mux.select_channel(2)
    L = sensor.distance_cm() or 999
    mux.select_channel(3)
    C = sensor.distance_cm() or 999
    mux.select_channel(4)
    R = sensor.distance_cm() or 999
    return L, C, R

while True:
    L, C, R = read_sensors()

    if C > STOP_CM and L > SIDE_CM and R > SIDE_CM:
        drive_forward()                     # all clear
    elif L < SIDE_CM and C < STOP_CM and R < SIDE_CM:
        stop()                               # cornered — back up
        reverse()
        time.sleep_ms(REVERSE_MS)
        turn_right()
        time.sleep_ms(TURN_MS)
    elif L < SIDE_CM:
        stop()
        turn_right()                         # wall on left → turn right
        time.sleep_ms(TURN_MS)
    elif R < SIDE_CM:
        stop()
        turn_left()                          # wall on right → turn left
        time.sleep_ms(TURN_MS)
    elif L >= R:
        stop()
        turn_left()                          # center blocked, left is more open
        time.sleep_ms(TURN_MS)
    else:
        stop()
        turn_right()
        time.sleep_ms(TURN_MS)

    time.sleep_ms(50)
1
Test in a confined space

Set up a simple arena — four walls or boxes. Run the avoidance program and let L.E.O. navigate on its own for 2 minutes. It should not get permanently stuck.

2
Adjust SIDE_CM and TURN_MS as needed

Wider arenas can use a smaller SIDE_CM. Tighter spaces may need a larger one. If turns undershoot, increase TURN_MS.

✓
Checkpoint 3

L.E.O. navigates a confined space for at least 2 minutes without getting permanently stuck against a wall.

4
Challenges
varies
C1 Course Navigation

Set up a simple obstacle course — three boxes in a row with gaps between them. Can L.E.O. navigate through all the gaps without touching any box?

C2 Speed Tuning

Increase the drive speed (or motor duty cycle) by 25%. Does the robot still stop cleanly? You may need to increase STOP_CM to compensate for the added momentum. Document the relationship between speed and required stopping distance.

ADV Proportional Wall Following

Use the right sensor to follow a wall at a constant distance. Replace the fixed turns with proportional correction:

  • Set a target distance (e.g., 20 cm from the right wall)
  • Calculate error = right_cm - target
  • Calculate correction = Kp × error where Kp ≈ 2–5
  • Apply correction to the left/right motor balance while driving forward

Start with a long straight wall. Add a corner once it's tracking smoothly.

Q1

Q2

The code reads sensors sequentially (one at a time via the mux). Each full scan takes about 200 ms. How would the robot behave differently if you only read the center sensor? What would you gain and what would you lose?
