Save it as imu_test.py.

3
Copy, paste, and run the starter code
imu_test.py 
import machine, struct, time

i2c = machine.I2C(0, scl=machine.Pin(1), sda=machine.Pin(0), freq=400000)

# Select your mux channel (ask your teacher which channel your IMU is on)
IMU_CHANNEL = 0
i2c.writeto(0x70, bytes([1 << IMU_CHANNEL]))

IMU_ADDR = 0x68
# Wake the IMU
i2c.writeto_mem(IMU_ADDR, 0x6B, bytes([0x00]))
time.sleep_ms(100)
print("IMU awake")

# Read gyro Z in a loop
def read_gyro_z():
    data = i2c.readfrom_mem(IMU_ADDR, 0x47, 2)
    raw  = struct.unpack('>h', data)[0]
    return raw / 131.0

while True:
    print(f"Gyro Z: {read_gyro_z():.2f} °/s")
    time.sleep_ms(100)

Integrate Yaw & Drive Straight
~20 min

Now track how much the robot has rotated and use that to keep it driving straight. You will integrate the gyro's angular velocity to get a running angle — then nudge the motors to correct any drift.

1

Stop the program in Thonny, then create a new file called heading_hold.py.

2
Copy the setup code from Part 1

At the top of heading_hold.py, copy your i2c init, mux select, IMU wake, and read_gyro_z() function from Part 1.

3
Add the heading-hold drive function below
heading_hold.py — drive function 
import motor

LOOP_MS   = 20
DEAD_BAND = 2.5   # degrees of acceptable drift

def drive_straight_imu(speed=50, duration_ms=2000):
    """Drive forward for duration_ms holding IMU heading."""
    yaw = 0.0
    t0  = time.ticks_ms()
    while time.ticks_diff(time.ticks_ms(), t0) < duration_ms:
        gz   = read_gyro_z()
        yaw += gz * (LOOP_MS / 1000.0)   # integrate: °/s × s = degrees

        if   yaw >  DEAD_BAND:
            motor.drive(speed - 8, speed)   # drifted right → slow left motor
        elif yaw < -DEAD_BAND:
            motor.drive(speed, speed - 8)   # drifted left  → slow right motor
        else:
            motor.drive(speed, speed)
        time.sleep_ms(LOOP_MS)
    motor.drive(0, 0)

drive_straight_imu(speed=50, duration_ms=3000)

3
tank_turn(deg) & Drive a Square
~20 min

Now add precise turns. tank_turn(deg) rotates L.E.O. in place by exactly that many degrees using the gyro — no encoders needed.

1
Add tank_turn() below drive_straight_imu()
heading_hold.py — turn function 
def tank_turn(degrees, speed=30):
    """
    Turn in place. Positive = clockwise (right), negative = left.
    """
    target    = abs(degrees)
    direction = 1 if degrees > 0 else -1
    yaw       = 0.0

    while abs(yaw) < target - 2:   # stop 2° early to account for coast
        gz   = read_gyro_z()
        yaw += gz * (LOOP_MS / 1000.0)
        motor.drive(direction * speed, -direction * speed)
        time.sleep_ms(LOOP_MS)

    motor.drive(0, 0)
    time.sleep_ms(150)   # brief settle before next move
2
Test the turn alone

Run tank_turn(90). Measure the actual angle with a protractor or by eye. Adjust speed if the result is far off.

Challenges

Finished early or want a harder problem? Work through these in order.

C-1 Left-Turn Square

Modify the square program to use tank_turn(-90) instead of tank_turn(90). Run it and compare — does L.E.O. stay as square when turning left?

C-2 Right Triangle

Drive three sides of a triangle with 120° turns. Plan the turn values on paper first — think about the exterior angle of an equilateral triangle before you write a single line of code.

C-3 Speed vs. Accuracy

Test tank_turn(90) at speeds 20, 30, 40, and 50. Record the actual angle turned for each. What is the tradeoff between speed and accuracy? At what speed does accuracy fall off most sharply?

C-4 Extension: Figure-8

Drive a figure-8 path. This requires both right and left turns with direction reversals between the two loops. Sketch the path on paper and label each segment's direction before coding.

Q1 — Gyro Integration

What is gyro integration? In your own words, explain what the line yaw += gz * (LOOP_MS / 1000.0) is calculating. What units does gz have, and what units does yaw end up in?

Q2 — Gyro Drift

Q3 — Dead Band Tradeoff

You increase DEAD_BAND from 2.5° to 10°. How does this change the robot's straight-line driving? Is a bigger dead band always worse — or can it ever be an advantage?

Q4 — Turn Accuracy
