What Is a Microcontroller?

A microcontroller (uC) is a tiny computer on a single chip. Unlike your laptop, it has no operating system, no hard drive, and no display — just a processor, some memory, and a set of input/output pins that connect directly to the physical world.

Your program runs on a loop — over and over — responding to sensors and controlling motors, LEDs, and other devices in real time.

What a uC can do

  • Read sensors (distance, light, touch)
  • Control motors and servos
  • Make decisions based on sensor data
  • Communicate over Wi-Fi or Bluetooth
  • Run for months on a small battery

On the interface board

  • I²C multiplexer for 3 ultrasonic sensors
  • 5 IR sensor inputs
  • 2 servo headers
  • 3 mechanical switches
  • 3 ADC inputs
  • Onboard indicator LEDs for every GPIO

One important rule

GPIO pins are 3.3 V logic and can only source ~4 mA each (50 mA total). This is enough for LEDs and sensor signals — never enough for motors. The motor driver on the board handles motor current. You just tell it which direction and how fast.

Why MicroPython?

MicroPython is a lean version of Python 3 designed to run on microcontrollers. It has the same syntax as the Python used in data science, web development, and AI — so learning it here transfers directly.

Python is everywhere

  • Most popular language for data science & AI
  • Used at Google, NASA, SpaceX, and nearly every tech company
  • Top language for beginners and professionals alike
  • Free, open source, huge community
