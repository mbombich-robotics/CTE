Activity 5.3 — Reading Switches

No extra wiring needed — the switches are already on the interface board. Work through each part in order and raise your hand at each checkpoint.

~45 minutes Lesson 5.2
1
Find the Switches
~10 min

Your interface board has two mechanical switches built in. Locate them now — they're labeled SW_2 and SW_3 on the board silkscreen. They look like small rectangular tactile buttons that click when pressed.

📌
Pin assignments

SW_2 is on GP12 (J18 header, pin 16). SW_3 is on GP16 (J20 header, pin 1). Both use Pin.PULL_DOWN — pressed gives 1, released gives 0.

Type these commands in the Thonny Shell, one at a time. Press Enter after each line.

Shell — type line by line
>>> from machine import Pin
>>> sw2 = Pin(12, Pin.IN, Pin.PULL_DOWN)
>>> sw2.value()
0
>>> # Now hold SW_2 down and run this again:
>>> sw2.value()
1

Repeat for SW_3:

Shell
>>> sw3 = Pin(16, Pin.IN, Pin.PULL_DOWN)
>>> sw3.value()     # should be 0
>>> # Hold SW_3 and run again:
>>> sw3.value()     # should be 1
💡
What you're seeing

When the switch is open (not pressed), the pull-down resistor holds the pin at GND → value() = 0. When you press it, the switch connects the pin to 3.3V, overriding the pull-down → value() = 1. The REPL reads it the instant you call value() — there's no continuous loop yet.

✋
Checkpoint 1

You got 0 when released and 1 when pressed for both SW_2 and SW_3. Raise your hand before continuing.

2
Switch-Controlled LED
~20 min

Now you'll write a program that runs in a continuous loop and responds to the switch in real time. The LED should be on while SW_2 is held, and off when it's released.

1
Open a new file in the editor

Click in the editor panel (top). If there's old code, select all (Ctrl + A) and delete it.

2
Type this program

Indentation matters — the three lines inside while True: must start with 4 spaces. Inside the if and else blocks, add 4 more spaces (8 total).

main.py
from machine import Pin

sw2 = Pin(12, Pin.IN, Pin.PULL_DOWN)
led = Pin("LED", Pin.OUT)

while True:
    if sw2.value() == 1:   # SW_2 pressed
        led.value(1)        # LED on
    else:
        led.value(0)        # LED off
3
Save and run

Press Ctrl + S → save to Raspberry Pi Pico as main.py. Then press F5. Hold SW_2 — the onboard LED should light up. Release — it should go off.

🔍
How the loop works

The while True loop runs hundreds of times per second. Each iteration calls sw2.value(), reads the current pin voltage, and immediately sets the LED. Because it's looping so fast, the response feels instant to your finger.

✋
Checkpoint 2

Holding SW_2 turns the LED on; releasing turns it off. Show the teacher before moving to Part 3.

3
Two-Switch Logic
~15 min

Python's and, or, and not operators let you combine multiple conditions. You'll use both switches to create different LED behaviors.

1
Add SW_3 to your program

Replace your current main.py with this version, which reads both switches:

main.py — two switches
from machine import Pin

sw2 = Pin(12, Pin.IN, Pin.PULL_DOWN)
sw3 = Pin(16, Pin.IN, Pin.PULL_DOWN)
led = Pin("LED", Pin.OUT)

while True:
    a = sw2.value()   # 1 if SW_2 pressed
    b = sw3.value()   # 1 if SW_3 pressed

    if a == 1 and b == 1:   # both pressed
        led.value(1)
    else:
        led.value(0)
2
Test and observe

Run the program. Try: only SW_2, only SW_3, both at once, neither. Confirm the LED only lights when both are held.

3
Change the condition to or

Replace and with or on the if line. Save and run. Now the LED should light when either switch is pressed. Test all four combinations again.

4
Exclusive OR — light only when exactly one is pressed

Change the condition to: if (a == 1) != (b == 1):
This is true when a and b differ — one pressed but not both. Test it.

💡
Why this matters for robotics

Your robot will combine sensor readings the same way — "if IR sensor 1 sees a line and IR sensor 2 does not, turn left." Logic operators are the decision-making backbone of every autonomous behavior.

✋
Checkpoint 3 — show the teacher

Demonstrate and logic, then or logic, by pressing combinations of SW_2 and SW_3.

Challenges
finish early?

Start from your working two-switch program. Each challenge builds a new behavior. Try one at a time.

C1 Blink on Press

Instead of staying on while held, make the LED blink at 5 Hz (0.1s on / 0.1s off) while SW_2 is pressed, and stay off otherwise. You'll need import time and a time.sleep() inside the if block.

C2 Count Presses

Count how many times SW_2 is pressed and print the count to the Shell. The tricky part: you want to count one press per button down, not every loop iteration the button is held.

Hint: save the previous state and only increment when the state changes from 0 to 1. After detecting a press, wait 20ms — mechanical switch contacts bounce briefly on contact, and the sleep lets the signal settle before the next check:

edge detection + debounce hint
import time

count = 0
prev = 0

while True:
    curr = sw2.value()
    if curr == 1 and prev == 0:       # rising edge — just pressed
        count += 1
        print(count)
        time.sleep_ms(20)            # debounce: wait out contact bounce
    prev = curr
C3 Toggle

Each press of SW_2 should toggle the LED on or off — press once to turn it on, press again to turn it off. Use the edge detection pattern from C2 and a variable to track the LED state.

C4 Morse-Code Button

Use SW_2 as a morse code key: while it's held, the LED is on. When you release, measure how long it was held. If under 0.3s, print "·" to the Shell; if 0.3s or longer, print "—".

You'll need import time and time.ticks_ms() to record when the button was pressed, and time.ticks_diff() to calculate the duration. Look these up in the Pico 2W Reference (Timing section).
