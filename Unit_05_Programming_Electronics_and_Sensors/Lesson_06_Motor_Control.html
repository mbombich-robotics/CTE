H-Bridge: Direction Control

A DC motor spins in the direction current flows through it — reverse the current and it spins the other way. The Pico's GPIO pins can't do this on their own (only 4 mA, wrong voltage). That's what the H-bridge is for.

The VNH5019 driver on your interface board is an H-bridge. You give it two logic signals — INA and INB — and it uses those to switch higher-current, higher-voltage power to the motor in the right direction.

The rule

Two pins per motor. Their combination decides direction:

  • INA=1, INB=0 → motor spins forward
  • INA=0, INB=1 → motor spins backward
  • INA=0, INB=0 → motor coasts (off)
  • INA=1, INB=1 → motor brakes hard

Your robot has two motors

Left motor (Motor A) and right motor (Motor B) each have their own INA/INB pair. To turn, you run them in opposite directions. To go straight, run them in the same direction.

PWM: Speed Control

Direction tells the motor which way to spin. PWM (Pulse-Width Modulation) controls how fast. Instead of a steady voltage, PWM switches the motor on and off thousands of times per second. The percentage of time it's on is the duty cycle.

In MicroPython, duty_u16() sets the duty cycle as a number from 0 (fully off) to 65535 (fully on). The interface board runs motors at 20 kHz — above human hearing so you won't hear a whine.

motor.py converts for you

motor.set_speed(100) # full speed motor.set_speed(50) # half speed motor.set_speed(25) # quarter speed motor.stop() # off

The library multiplies your 0–100 value by 655.35 internally — you never touch the raw number.

Why does this matter?

You can run motors at full speed for straight lines and then slow down for tight turns — all in the same program. Speed is just a number.

Your motor.py Module

Instead of typing raw pin numbers every time, you'll save a helper file called motor.py on the Pico. Then any program can import motor and call clean functions.

from machine import Pin, PWM # Left motor — Motor A _L_INA = Pin(2, Pin.OUT) _L_INB = Pin(3, Pin.OUT) _L_PWM = PWM(Pin(4)) _L_PWM.freq(20000) # Right motor — Motor B _R_INA = Pin(5, Pin.OUT) _R_INB = Pin(6, Pin.OUT) _R_PWM = PWM(Pin(7)) _R_PWM.freq(20000) FULL = 65535 _speed = FULL # current duty cycle — set via set_speed() def set_speed(pct): # pct = 0 to 100 global _speed _speed = max(0, min(65535, int(pct / 100 * 65535))) def _drive(la, lb, ra, rb): _L_PWM.duty_u16(_speed); _R_PWM.duty_u16(_speed) _L_INA.value(la); _L_INB.value(lb) _R_INA.value(ra); _R_INB.value(rb) def forward(): _drive(1, 0, 1, 0) def backward(): _drive(0, 1, 0, 1) def left(): _drive(0, 1, 1, 0) def right(): _drive(1, 0, 0, 1) def stop(): _L_PWM.duty_u16(0); _R_PWM.duty_u16(0) _L_INA.value(0); _L_INB.value(0) _R_INA.value(0); _R_INB.value(0)

Once motor.py is saved to the Pico, any program can use it:

import motor import time motor.forward() # full speed (default) time.sleep(1) motor.set_speed(50) # switch to half speed motor.right() time.sleep(0.5) motor.stop()
