Control statements Description 
if condition:
  ...
A control statement that performs instructions based on whether a condition is true. The condition must evaluate to a true or false value. 
if condition:
  ...
else:
  ... 		An if/else tests for both true and false results of a conditional expression. When the condition evaluates to true, the code below the if and before the else executes; when the condition evaluates to false, the code in the else executes. 
if condition1:
  if condition2:
     ...

A nested if statement is one if statement indented in another. The second if statement with condtion2 will only execute when the first condition1 is true. You can also nest an if statement in an else clause.
if condition1:
  ...
else:
  if condtion2:
    ... 
wait(time, units) Pauses program execution for the specified time. 
while True:
  ... 		A control statement that executes indefinitely. 

The while statement

Description

while [condition]:

Identifies a section of code to repeat while the condition evaluates to true. An always-true condition, as in while True, will run forever.

The if/else statement

Description

if btn.is(opens in a new tab)_pressed:
   led.on()
else:   
     led.off()

Tests for some conditions. When the condition evaluates to true, the code below the if and before the else executes; when the condition evaluates to false, the code in the else executes.

The while not statement

Description

while not [condition]

Use a not to repeat until the condition evaluates to false (not true). For example, the following will iterate until the user presses the pi-top cancel button.
          while not screen.cancel_button.is(opens in a new tab)_pressed:
                 ...

The if/elif/else statement

Description

if a < 0:
         print("neg")
elif a > 0:     
         print("pos")
else:
          print("0")

elif combines an else and an if so you can test additional conditions in an if statement. Use as many elifs inside an if statement as you want.

The for statement

Description

for i in range(10):  

Identifies a section of code to repeat.
