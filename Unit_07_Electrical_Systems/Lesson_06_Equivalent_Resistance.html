What Is Equivalent Resistance?

R_eq is the single resistor value that would draw exactly the same current and produce exactly the same voltage drop as an entire network of resistors. It's how we simplify complex circuits to make analysis tractable.
  • A circuit with 10 resistors can be reduced to one equivalent resistor without changing the current drawn from the supply
  • R_eq is found by applying series and parallel formulas repeatedly until one number remains
  • R_eq is a mathematical tool — you rarely build it physically. You calculate it to find total current, then work backward to individual branches.
  • Quick sanity checks: series R_eq > any individual R; parallel R_eq < any individual R

Series Equivalent Resistance

R_eq (series) = R₁ + R₂ + R₃ + … + Rₙ — just add them all up.
  • Series means the resistors share the SAME current path — they're end-to-end
  • Adding any resistor in series increases R_eq (and therefore reduces total current)
  • The formula works for any number of resistors
  • Example: 100 Ω + 220 Ω + 470 Ω = 790 Ω
  • After finding R_eq: use Ohm's Law to get total current: I = V_supply / R_eq
  • Then use Ohm's Law on each resistor to find its voltage drop: V_n = I × Rₙ

Parallel Equivalent Resistance

1/R_eq (parallel) = 1/R₁ + 1/R₂ + … + 1/Rₙ — add the reciprocals, then take the reciprocal of the result.
  • Each parallel branch is an independent path — adding branches gives current MORE ways to flow, so total resistance DECREASES
  • R_eq is always less than the smallest individual resistor
  • 2-resistor shortcut: R_eq = (R₁ × R₂) / (R₁ + R₂)
  • N equal resistors in parallel: R_eq = R / N (e.g., four 100Ω in parallel = 25Ω)
  • Example: 100Ω ∥ 300Ω → R_eq = (100 × 300) / (100 + 300) = 30000 / 400 = 75Ω

Combination Circuits — Step-by-Step Reduction

A combination circuit has both series and parallel sections. Reduce it one group at a time.
  1. Identify sections that are purely in series or purely in parallel — look for nodes where wires join or split.
  2. Simplify the innermost group first — usually a parallel group nested inside a series path.
  3. Replace that group with its R_eq on the schematic (redraw if helpful).
  4. Repeat until only one resistor remains.
  5. Work backward from R_eq to find individual branch currents and voltages using Ohm's Law.

Combination Circuit — Worked Example

  1. Given: R₁=150Ω in series with a parallel group of R₂=68Ω ∥ R₃=100Ω, all in series with R₄=220Ω. Supply = 6V.
  2. Step 1: R₂ ∥ R₃: 1/R_p = 1/68 + 1/100 = 0.01471 + 0.01 = 0.02471 → R_p = 40.5Ω
  3. Step 2: R_eq = R₁ + R_p + R₄ = 150 + 40.5 + 220 = 410.5Ω
  4. Step 3: I_total = 6 / 410.5 = 14.6 mA
  5. Step 4: V across parallel group = 14.6mA × 40.5Ω = 0.59V
  6. Step 5: I through R₂ = 0.59/68 = 8.7mA; I through R₃ = 0.59/100 = 5.9mA → Check: 8.7 + 5.9 ≈ 14.6mA ✓

Tinkercad Verification (PLTW POE_314)

  • Build each circuit in Tinkercad (Circuits view)
  • Place an ammeter in series with the supply and a voltmeter across the whole network
  • Calculate R_eq from measurements: R_eq = V_supply / I_total (Ohm's Law)
  • Compare to algebraically calculated R_eq — they should match within a few Ω (Tinkercad uses ideal values)
  • If they don't match, check whether components are actually in the topology you think they are
Tinkercad is useful for verification, not for learning. Always calculate first, then simulate to check. Using the simulator first and then reverse-engineering the algebra misses the learning goal.

Special Cases Worth Memorizing

Two Equal Resistors in Parallel

  • R_eq = R / 2
  • Example: two 470Ω in parallel = 235Ω
  • Three equal: R/3. Four equal: R/4.
  • Useful when designing balanced circuits

One Very Small Parallel Resistor

  • If R₁ >> R₂ (say 10kΩ ∥ 10Ω), R_eq ≈ R₂
  • The tiny resistor dominates — it short-circuits the big one
  • This is why you should never accidentally put a low-resistance path in parallel with a circuit you care about
A wire (0Ω) in parallel with any resistor = 0Ω equivalent resistance. This is what a short circuit does — it bypasses all resistance.
