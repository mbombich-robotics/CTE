Series Circuits

In a series circuit, there is only one path for current. All current must flow through every component in the chain.
  • Current is the same through every component: I₁ = I₂ = I₃ = I_total
  • Voltage splits across the components: V₁ + V₂ + V₃ = V_supply
  • Total resistance adds up: R_total = R₁ + R₂ + R₃ + …
  • If any component fails (open), the entire circuit goes dead — no path for current

Series Math

  1. R_total = R₁ + R₂ + R₃ + … — just add them all up
  2. I = V_supply / R_total — current is the same everywhere
  3. V_n = I × Rn — voltage drop across each component by Ohm's Law
  4. Check: V₁ + V₂ + V₃ = V_supply (voltage drops must sum to supply)
Example — 9V supply, R₁ = 100Ω, R₂ = 200Ω, R₃ = 300Ω → R_total = 600Ω → I = 9/600 = 15mA → V₁ = 15mA × 100Ω = 1.5V, V₂ = 3V, V₃ = 4.5V → Check: 1.5 + 3 + 4.5 = 9V ✓

Parallel Circuits

In a parallel circuit, there are multiple paths for current. Each branch provides an independent route from + to −.
  • Voltage is the same across every branch: V₁ = V₂ = V₃ = V_supply
  • Current splits among the branches: I_total = I₁ + I₂ + I₃
  • Total resistance decreases: 1/R_total = 1/R₁ + 1/R₂ + 1/R₃ + …
  • If one branch fails (open), other branches continue to work independently

Parallel Math

  1. 1/R_total = 1/R₁ + 1/R₂ + 1/R₃ — add the reciprocals, then take the reciprocal of the result
  2. Special case (2 resistors): R_total = (R₁ × R₂) / (R₁ + R₂) — the "product over sum" shortcut
  3. I_n = V_supply / R_n — each branch current by Ohm's Law
  4. I_total = I₁ + I₂ + I₃ — total current from the supply
  5. Check: I_total × R_total = V_supply ✓
Example — 9V supply, R₁ = 100Ω, R₂ = 300Ω → R_total = (100 × 300)/(100+300) = 30000/400 = 75Ω → I₁ = 9/100 = 90mA → I₂ = 9/300 = 30mA → I_total = 120mA → Check: 120mA × 75Ω = 9V ✓

Series vs. Parallel: Side-by-Side

Property Series Parallel
Current through components Same everywhere: I₁ = I₂ = I₃ Splits: I_total = I₁ + I₂ + I₃
Voltage across components Splits: V₁ + V₂ + V₃ = V_supply Same: V₁ = V₂ = V₃ = V_supply
Total resistance formula R_total = R₁ + R₂ + R₃ 1/R_total = 1/R₁ + 1/R₂ + ...
R_total vs. largest R Always bigger than any single R Always smaller than smallest R
If one component opens Entire circuit goes dead Only that branch goes dead
Two quick mental checks: (1) parallel R is always LESS than the smallest individual R. (2) series R is always MORE than the largest individual R. If your answer violates this, recalculate.

Why Houses Use Parallel Circuits

Series Wiring (Bad for Houses)

  • Every outlet shares the same current path
  • If you plug in a 1000W heater, it changes the current through every other outlet
  • If any outlet or appliance fails open, every appliance in the house goes dead
  • Voltage drops with each appliance added — devices get dim/slow

Parallel Wiring (How It's Actually Done)

  • Every outlet gets the full 120V regardless of what else is plugged in
  • Each appliance draws its own current; adding appliances doesn't affect others
  • If one appliance fails, only that branch stops — everything else works
  • Total current (and cost) increases as you add more devices
Your home's circuit breakers respond to total current (I_total). When you run too many appliances on one circuit, I_total exceeds the breaker's rating and it trips to protect the wiring.
