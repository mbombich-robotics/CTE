Motion in Machines

  • Rotational — spinning around a fixed axis (wheels, gears, pulleys)
  • Linear — straight-line motion in one direction (a drawer, a piston stroke)
  • Reciprocating — back-and-forth linear motion (sewing needle, engine piston)
  • Oscillating — back-and-forth rotational/arc motion (pendulum, windshield wiper)
Linkages are the bridges between these motion types.

The Four-Bar Linkage

  • Four rigid bars (links) connected at pivot joints (pins)
  • One link is fixed (the frame/ground link)
  • The driver link rotates or oscillates, driving the output link
  • The coupler link connects driver to output
The four-bar linkage is the most common mechanism in engineering. Legs, windshield wipers, suspension, and robot arms all use it.

Grashof's Rule

If the shortest link + longest link ≤ sum of the other two, at least one link can fully rotate.

Link Ratios Matter

Changing link lengths changes the output motion path — same principle, wildly different behavior.

🔧 Fran's Gate Problem Fran's barn gate needs a latch that can be opened with one hand and stays locked when released. Design a four-bar linkage latch mechanism.
  1. Sketch the gate and latch position (open vs. closed)
  2. Identify what motion type you need at the handle (rotational → linear lock motion)
  3. Draw the four links and label: ground, driver, coupler, output
  4. Test on paper: does the latch snap shut? Can it be opened easily?

From Sketch to Build

  • Start with the required OUTPUT motion — what must the end of the mechanism do?
  • Work backward: what INPUT produces that output?
  • Sketch multiple configurations before picking one
  • Consider: range of motion, force advantage, compactness, failure modes
  • A good linkage feels inevitable — the motion looks "right"

Over-constrained

Too many links → mechanism jams or is rigid. No motion at all.

Under-constrained

Too few constraints → floppy mechanism. Unpredictable motion.

Where You've Seen This

  • 🚗 Car suspension — double-wishbone is a four-bar linkage keeping the wheel vertical
  • ✂️ Scissors — crossed four-bar linkage; handles rotate, blades close linearly
  • 🦾 Robot arm — multiple four-bar stages linked in series
  • 🚪 Trunk lid mechanism — guided opening arc using a four-bar
  • 🪟 Windshield wipers — crank-rocker four-bar, converts rotational motor to oscillating wipe
If it moves predictably, there's probably a linkage behind it.

Will It Move?

  • A rigid body in a plane has 3 degrees of freedom (DOF): x, y, rotation
  • Each pinned joint removes 2 DOF (constrains x and y)
  • Each link adds 3 DOF
  • Formula: DOF = 3(L − 1) − 2J  where L = links, J = joints
Worked example: Four-bar linkage: L=4, J=4 → DOF = 3(3) − 2(4) = 9 − 8 = 1 ✓ (one input drives the whole mechanism)
DOF = 0 → rigid structure.   DOF > 1 → needs multiple inputs.

Activity: Design a Latch

  1. Sketch two designs: one that fully rotates (crank) and one that oscillates (rocker)
  2. Calculate DOF for each design
  3. Build your chosen design using VEX linkage components
  4. Test: does it latch reliably? Does it release cleanly?
  5. Document: photograph mechanism open and closed

Turn In

  • DOF calculation shown
  • Photo of built mechanism (open + closed position)
  • Reflection: what motion type does your latch use? What would break it?
