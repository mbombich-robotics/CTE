Decision Matrix

Design decisions should be based on analysis and logic, not on opinion. Engineers and designers use a variety of tools to evaluate options and justify decisions. One popular tool is a decision matrix. 

TermDefinition
decision matrixA tool used to compare design solutions against one another using specific criteria.

Selecting the Best Solution Path

A decision matrix is a table that helps you systematically evaluate and compare multiple design choices to develop an overall rating for each choice. Because you rate each potential design solution relative to the other available solutions, the overall rating can help you select a solution path and provide evidence to support your decision. 

Using a Decision Matrix

Step 1: In the column heads, identify the criteria and constraints you will use to compare solutions. 

Criteria might include a variety of specifics related to development and use, such as:

  • material costs
  • development costs
  • manufacturing costs
  • reusability
  • geometry
  • connections
  • cleanliness
  • resilience
  • testability
  • life span
  • development time
  • size
  • company standards
  • safety
  • manufacturing capabilities
  • function

Step 2: List problem solution ideas in the Idea column.

Step 3: Create a rating scale(s).

Step 4: Rate each solution idea against each criterion or constraint using a rating scale.

Step 5: Sum the rating values for each solution idea in the Total column.

Use the Decision Matrix Template(opens in a new tab) to help you get started. An example of a completed decision matrix is provided in the Completed Decision Matrix interactive graphic. Note that before you evaluate ideas with the decision matrix, you should clearly document each idea with a conceptual model.

Rating Scale

A rating scale provides guidance to assign values for each design idea when compared against each criterion or constraint in the matrix. The Completed Decision Matrix interactive graphic shows two rating scale options—a ranking scale from 4 to 1 and a Yes/No scale. You can develop your own rating scales to address unique circumstances.

NOTE: The design process is iterative. You can use the decision matrix tool multiple times throughout a design process as you work to identify the best solution.
