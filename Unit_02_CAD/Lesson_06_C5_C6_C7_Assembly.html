Component Overview

C5 — Omni Wheel Mount

Purpose: holds the front omni wheels so L.E.O. can pivot and turn. Flat top plate (4 corner mounting holes) with two downward arms — one on each side — each with an axle bore.

New F360 tools: Multi-plane sketch · Reference geometry

Key specs

  • Arm spacing matches omni wheel axle width
  • Axle bore diameter matches omni wheel hub
  • 4 × M5 mounting holes on top plate
Lastname_OmniMount_v1-Base

C6 — IR Sensor Mount

Purpose: mounts at the front underside of the deck; holds the IR sensor bar at a consistent height above the ground for line following.

Shape: U-bracket — two vertical arms each with a flat mounting tab (one M5 hole each) on top; bottom web with a slot running its length.

New F360 tools: Mirror · Slot tool

Key specs

  • 1 × M5 hole on each mounting tab
  • Bottom web slot for sensor bar routing
Lastname_IRSensorMount_v1-Base

C7 — Ultrasonic Sensor Mount

Purpose: holds the HC-SR04 ultrasonic sensor at the front of L.E.O., facing forward.

Shape: vertical rectangular block with two large circular bores (emitter + receiver) through the face; L-shaped foot with 2 mounting holes.

New F360 tools: Large-bore circle (Inspect → Measure from HC-SR04 model) · L-bracket two-face extrude

Key specs

  • Bore OD: measure from HC-SR04 reference model
  • 2 × M5 mounting holes on L-foot
Lastname_UltrasonicMount_v1-Base

Techniques & Assembly

New This Lesson

Multi-plane sketch — after extruding the top plate, click the side face to start a new sketch there. This is how you draw the arms of C5 and the walls of C6.

Reference geometry — use an existing body edge as a reference line in a new sketch to ensure your new features stay aligned.

Mirror — Sketch → Mirror; select geometry and the mirror line. Creates perfectly symmetric features without drawing them twice. Used for both walls of C6.

Slot tool — creates a rectangular slot with rounded ends in one step. Use for the C6 bottom web channel.

L-bracket (two-face extrude) — for C7, extrude the vertical block on the first sketch, then sketch the horizontal foot on the bottom face and extrude it outward.

Final Assembly — End of Week 7

Your assembly must include all of the following, fully constrained:

  • Deck (C4) with all hole patterns finalized
  • C3 Motor Sleeve Mount × 2 (left and right)
  • C5 Omni Wheel Mount
  • C6 IR Sensor Mount
  • C7 Ultrasonic Sensor Mount
  • All components fully constrained — no free movement
  • Interference Check: zero collisions

The deck is NOT sent to CNC until the full assembly passes Interference Check with zero collisions.
