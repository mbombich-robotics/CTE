The slicer sits between your model and the printer. It converts geometry into the printer's language — a sequence of moves, temperatures, and flow rates called G-code.

⚠️ The slicer is where most print failures are decided

A good model sliced badly will fail. A great slicer setup with a bad model will also fail. Both sides matter — this lesson covers both.

Export from Fusion 360

Fusion stores your part as a parametric model. You need to export it as a static mesh the slicer can read.

1

Choose 3MF, not STL

In Fusion: File → Export. Set the file type to .3mf. 3MF preserves units, scale, and orientation more reliably than STL. BambuStudio handles it natively.

2

Name your file correctly

Format: Lastname_ComponentName_v1.3mf
Example: Smith_WheelHub_v1.3mf

3

Save location

Save to your Desktop or a local folder, not OneDrive or a network share. Slicers sometimes have trouble reading files from cloud-synced folders.

4

Check the scale

When you open the file in BambuStudio, verify it appears at the correct size. A 25mm bore should read as ~25mm on-screen, not 0.025mm or 25,000mm.

BambuStudio

BambuStudio is the slicer software for all Bambu Lab printers. It handles everything from orienting your part to sending the print job over the network.

Install

  • Download from bambulab.com/software
  • Install like any other program — Next → Next → Finish
  • On first launch it will ask you to sign in or create a Bambu account — use the class credentials your teacher provides
  • Select your printer model during setup: P1S or P2S

The Interface

  • Build plate — the gray grid in the center. Parts go here.
  • Left panel — your imported objects
  • Right panel — print settings (profile, infill, supports)
  • Top toolbar — orient, arrange, cut, and slice tools
  • Slice now button — generates G-code when you're ready

Ender 3 Users — Use Creality Print Instead

BambuStudio does not support Ender 3 printers. Download Creality Print from creality.com. The workflow on the next slides is identical — same concepts, different interface.

Orient Your Part

How you place the part on the build plate determines print time, strength, and whether you need supports. This decision matters more than most slicer settings.

Rules of Thumb

  • Flattest face down. Maximizes contact with the bed, minimizes overhangs.
  • Critical bores vertical. A circular bore printed horizontally prints as an oval due to layer stacking. Printed vertically, it's actually round.
  • Strength follows layer lines. The part is strongest parallel to the layers and weakest between them. Orient so expected forces run parallel.
  • Avoid unsupported overhangs > 45° unless you're willing to add supports and clean them up afterward.

Tools in BambuStudio

  • Auto Orient — click this first. Good starting point, not always optimal.
  • Place on Face — click a face; that face snaps to the build plate.
  • Rotate — drag the arc handles. Hold Shift for 45° snaps.
  • Mirror — flip the part if your design is handed (left/right).

After orienting, look at the part from all angles. Hover slowly — BambuStudio will highlight overhangs in red.

Print Profile

Select from the dropdown at the top of the right panel. For most robot parts: 0.20mm Standard. This sets layer height, speed, and temperature automatically.

Don't start by tweaking individual settings. Start with the right profile and adjust only if you have a specific reason.

Infill Pattern

Gyroid or Grid for robot parts. Gyroid is isotropic — equally strong in all directions — at the cost of slightly longer print time.

Infill only affects the inside. More infill = heavier, stronger, slower. For brackets and mounts, 40% grid is the default unless your teacher specifies otherwise.

Supports

FDM printers deposit material layer by layer. A layer has to rest on something — either the previous layer or a support structure. Overhangs beyond ~45° need support.

When You Need Supports

  • Any overhang angle steeper than 45° from vertical
  • Horizontal holes on the side of a part (the top half of the bore needs support)
  • Bridging spans longer than ~60mm

Best solution: re-orient the part so the overhang faces down. Supports you don't add can't cause problems.

Support Types in BambuStudio

  • Normal — grid structure, fast to generate, harder to remove. OK for simple overhangs.
  • Tree — organic branching structure, touches the part at fewer points, much easier to snap off. Better for most robot parts.
  • None — for well-oriented parts. Always aim for this first.

Removing Supports

Use needle-nose pliers, flush cutters, or your fingers for tree supports. Always de-risk removal by clamping the part — don't pull toward your hand. After removal, clean up the surface with a deburring tool or sandpaper if a smooth face is needed.

Slice and Preview

Slicing converts your 3D model into a stack of 2D cross-sections with exact move instructions for the printer. The preview is your last chance to catch problems before plastic is wasted.

1

Click "Slice Now"

BambuStudio processes the geometry. This takes a few seconds to a minute depending on part complexity. A progress bar appears at the bottom.

2

Check the preview

Use the layer slider on the right to scrub through the print layer by layer. Look for: supports where expected, no floating islands, consistent infill, and a solid base layer.

3

Check the estimate

BambuStudio shows print time and filament usage. If a simple bracket estimates 4 hours, something is wrong — check your infill, layer height, or whether you accidentally scaled the part up.

4

If something looks wrong, go back

Click Edit Plate to return to the 3D view. Re-orient, adjust settings, and re-slice. Slicing is fast — iterate freely before committing to a print.

Send to Printer

Once you're satisfied with the preview, you send the sliced job to the printer. Bambu Lab printers support three methods:

☁️

Cloud (Recommended)

Click Print → Send. Select the printer from the dropdown. The job uploads and the printer starts after you confirm on its touchscreen. Both you and your teacher can see the queue.

🔌

LAN (Direct)

If cloud is unavailable, BambuStudio can send directly to the printer over the school network. Requires the printer to be on the same WiFi. Same process — click Print, select LAN mode.

💾

SD Card

Export the sliced file as a .gcode.3mf to an SD card. Insert into the printer and select the file from the touchscreen. No network needed.

Print Queue — Be Considerate

Ten people sharing ten printers means planning ahead. Send your job, note which printer accepted it, and check back on the estimated finish time. Don't queue multiple jobs before your first one finishes.

Prep the Physical Printer

The slicer handles the software side. Before your job starts, verify the physical printer is ready.

1

Bed check

The build plate should be clean and flat. Wipe the cool plate or PEI plate with isopropyl alcohol (IPA) before each print. Skin oils prevent adhesion. If the previous print left residue, clean it off — don't print on top of it.

2

Filament loaded and primed

Check that PLA filament is loaded and feeding cleanly through the AMS (Bambu) or the extruder (Ender). If the filament looks brittle, discolored, or wet-sounding during extrusion, notify your teacher — hygroscopic filament needs to be dried.

3

Nozzle clear

If there's a blob of old plastic hanging off the nozzle, remove it with tweezers (careful — it's hot) before starting. The Bambu P1S and P2S run an automatic purge before printing; watch it and make sure it clears cleanly.

4

Confirm on the touchscreen

After sending the job, the printer's screen prompts you to confirm. Walk to the printer, verify the job name is yours, and tap Print. Never confirm a job that isn't yours.

During the Print

Watch the First Layer

The first layer is the most critical. It should be slightly squished into the bed — not sitting on top as a round filament strand. If it looks like a series of round noodles sitting on the surface, the nozzle is too far from the bed.

Signs of a good first layer:

  • Slight sheen — filament is pressed flat
  • Lines touching each other, no gaps
  • Part not lifting at the corners

Do's and Don'ts

  • DO check back at the 15-minute mark
  • DO report failed prints to your teacher immediately — don't let it run into a pile of spaghetti
  • DON'T open the door on the P1S or P2S mid-print — the enclosure holds temperature and humidity stable
  • DON'T cancel someone else's print
  • DON'T pull a finished print off without cooling — the part is soft and will warp

Bambu AI Detection

The P1S and P2S have a camera and AI spaghetti detection. If the print detaches from the bed and starts producing a tangle, the printer will pause and notify you. Check BambuStudio's device panel or the Bambu Handy app to see live camera feed and status.

Post-Processing

The printer is done — but your part isn't. This step gets it ready to use.

1

Let it cool

Wait at least 5 minutes after the print finishes before removing the part. PLA is soft while warm — removing it too soon can warp the base. The build plate on Bambu printers will cool automatically and the part will release on its own.

2

Remove supports

Use needle-nose pliers for tree supports — they snap off cleanly. For normal support structures, use flush cutters to clear the grid, then pliers to peel away the remaining contact points. Always point the part away from you.

3

Test fit immediately

For robot components, test-fit the part as soon as you remove it. Check bore clearances, hole alignment, and snap-fit features now — while you still have time to reprint if needed. Don't wait until assembly day.

4

Iterate if needed

A bore that's 0.3mm too tight is a reprint, not a failure. Go back to Fusion, update the dimension, export, and queue again. Iteration is part of the process.

When Things Go Wrong

Most print failures come from a small set of causes. Learn to recognize them so you can fix the issue rather than just restarting and hoping.

Warping (Corners Lifting)

Cause: Bed temp too low, or the first layer didn't adhere well.

Fix: Clean the plate with IPA, check that bed temp is set correctly (60°C for PLA), and make sure the first layer height is calibrated (Z offset).

Stringing (Hairs Between Walls)

Cause: Nozzle temperature too high, or retraction settings too low.

Fix: Lower print temperature by 5°C, or increase retraction distance slightly. The P1S has a pre-tuned profile that minimizes this — make sure you're using it.

Layer Separation (Splitting)

Cause: Layers not fusing — temp too low, print speed too high, or wet filament.

Fix: Increase temperature by 5°C. If the filament is making crackling sounds during extrusion, it's wet — report it so it can be dried.

"Spaghetti" (Print Detached)

Cause: Part detached from the bed mid-print and the nozzle kept extruding into thin air.

Fix: Stop the print immediately. Remove the tangle carefully. Clean the bed and start over. Identify why it detached (dirty bed, bad first layer) before reprinting.

Ender 3 V3 KE — Creality Print

The Ender 3 V3 KE printers use the same workflow, but with Creality Print as the slicer instead of BambuStudio.

Install Creality Print

  • Download from creality.com → Software → Creality Print
  • On first launch, select printer: Ender-3 V3 KE
  • All profiles are pre-configured — use 0.20mm Standard as your default

The Ender 3 V3 KE uses Klipper firmware and supports direct WiFi printing. You can send jobs wirelessly the same way you would with BambuStudio.

Key Differences

  • The Ender 3 is open-frame — no enclosure. Don't print materials that need high ambient temperature (ABS, ASA). PLA is fine.
  • No AI detection. Watch the first layer manually.
  • The flexible spring-steel bed on the V3 KE makes part removal easy — flex the plate gently and the part pops off.
  • Bed leveling is automatic (CR Touch probe) but may need occasional re-calibration.

Same Core Skills

Orientation, infill, supports, preview, first layer monitoring — everything you learned in this lesson applies directly to Creality Print. The software looks different; the decisions are identical.
