What Is Multi-Color FDM?

  • 🎨 The Bambu AMS holds up to 4 spools and switches filament mid-print AMS = Automatic Material System. It sits beside the printer and feeds whichever color the print job needs, when it needs it.
  • 🔄 Every color change requires purging the old filament out of the nozzle The nozzle must flush residual color before printing the next one — this creates waste filament captured in the purge tower.
  • 🖨️ Result: one print, multiple distinct color regions Colors are hard boundaries — not gradients. Each region must be defined by a body or face before slicing.
  • ⚠️ Key constraint: more color changes = more purge waste Changing colors many times per layer balloons the purge tower size and print time. Keep colors grouped in the Z direction.

Designing for Multi-Color in Fusion 360

Approach A — Separate Bodies

  • Each body in Fusion 360 becomes its own object in the slicer.
  • Assign a different filament color to each body in Bambu Studio.
  • Best for large, distinct regions — a colored base, a contrasting top layer, separate decorative elements.
  • Plan body boundaries in F360 to align with where you want color changes.

Approach B — Face Painting

  • Paint specific faces of a body a different color directly in Bambu Studio.
  • No F360 changes needed — works on top of existing geometry.
  • Best for details, text, logos, or surface accents on an existing body.
  • Overrides the body color for painted faces only.
For P3 (Christmas ornament): Plan your colors BEFORE modeling so body boundaries in Fusion 360 align with where you want color changes. It is much harder to add color boundaries after the model is complete.

Bambu Studio — Import & Set Up

  1. Open Bambu Studio → New Project.
  2. Click Import (or drag-and-drop) your .f3d or .step file onto the build plate.
  3. In the top-left dropdown, select your printer profile (Bambu X1 or P1 series).
  4. Set layer height: 0.2mm (standard quality — fine for ornaments).
  5. Confirm bed temperature and filament type match what's loaded in the AMS (PLA is standard).
  6. Verify the model is centered on the build plate and oriented flat-side down.
  7. Take a screenshot of this setup screen — you will need it for D_P3B.

Assigning Colors to Bodies

Each body imported from Fusion 360 appears as a separate item in the model panel. Assign each body to an AMS slot before doing any face painting.
  1. In the left sidebar (model panel), expand the object list — each Fusion 360 body is listed separately.
  2. Click a body to select it. The body highlights in the 3D view.
  3. Right-click the body → "Change Filament" → select AMS slot 1, 2, 3, or 4.
  4. Each slot corresponds to a physically loaded filament color. The 3D preview updates in real time.
  5. Repeat for every body. Color every body before painting faces — face painting overrides the body color for specific faces only.

Not sure which spool is in which slot? Open the AMS panel (printer icon, top right) — it shows the filament color assigned to each slot number.

Face Painting

  1. Select the Paint tool (brush icon in the top toolbar).
  2. Choose "Color Paint" from the paint tool options.
  3. In the filament selector, pick the AMS slot color you want to apply.
  4. Click and drag across faces on the model to paint them that color. The brush highlights faces as you hover.
  5. Use the smoothing slider to control edge sharpness — lower = sharper boundaries, higher = feathered edges where layers transition.
  6. Face painting overrides the body color for those faces. Use it for details, text, logos, or gradients between regions.
Tip: You can un-paint a face by selecting the base body color and painting over it again. There is no destructive action — just re-paint.

The Purge Tower

  • Every filament switch generates waste filament — the nozzle must purge the old color before printing the new one.
  • Bambu Studio automatically adds a Purge Tower (also called Wipe Tower) to the build plate. It is printed alongside your model.
  • More color changes per layer = a bigger purge tower. If you switch between all 4 colors on every layer, the tower can consume as much filament as the model itself.

How to reduce purge waste

  • Minimize the number of unique colors per layer.
  • Group same-color features in the Z direction — if your red section is all on one side from bottom to top, there are fewer switches.
  • Avoid alternating colors that appear on every single layer.

Purge tower settings

  • If the tower tips over mid-print, increase tower width in Bambu Studio settings.
  • Enable brim on the tower for better bed adhesion.
  • Check the filament weight estimate for the purge tower in the weight summary — count it against your 200g budget.

Slicing & Checking Weight

  1. Click "Slice All" (top-right button). Bambu Studio processes the model and generates toolpaths.
  2. After slicing, check the print summary panel: total print time, filament usage by color (grams and meters), and layer preview.
  3. Use the layer slider (right side) to scrub through the print layer by layer — confirm color regions appear exactly where you expect them.
  4. For P3: total filament across ALL colors must be under 200g (including purge tower waste).
  5. If over 200g: reduce infill to 15% (fine for ornaments), reduce wall count to 2 walls, or simplify the model in Fusion 360.
  6. Take a screenshot of the slice preview and weight summary — this is required for D_P3B.

Common Issues & Fixes

Issue Fix
Color bleeds between regions in preview Check body/face boundaries in Fusion 360 — make sure bodies share a clean, watertight face with no gaps or overlaps.
Purge tower falls over mid-print Increase tower width in Bambu Studio settings, or enable a brim on the tower for better bed adhesion.
AMS jam Pause the print, unload the filament from the AMS, re-feed it slowly. Avoid over-twisted or tangled spools.
Color looks wrong in the preview In the model panel, verify which AMS slot each body is assigned to. The slot number must match the physical spool loaded in the AMS.
Underextrusion right after a color change Increase the purge volume in filament settings — the nozzle needs more material to fully clear the previous color.
