Component Overview

C4 — Robot Deck (CNC Cut — Polycarbonate)

The deck is the structural chassis of L.E.O. Unlike the printed components, the deck is CNC cut from polycarbonate. This means:

  • All interior corners must be filleted to at least the CNC bit radius (TBD — Mr. B will provide the bit diameter)
  • The deck is NOT cut until the full assembly passes an interference check in Fusion 360 — this mirrors real manufacturing workflow

Deck File — Version Naming

The deck file is started this week but lives throughout the rest of the unit. You will add hole patterns for each new component as they are positioned in the assembly. Version naming matters:

VersionWhat's Added
v1-Base (this week) Outer profile + C3 motor mount holes
v2-C5 Add C5 hole pattern after C5 is positioned
v3-C6 Add C6 hole pattern
v4-C7 Add C7 hole pattern
v5-Final All holes complete — cleared for CNC

Assembly Concept

In Fusion 360, an assembly is a separate file that links to your component files — not copies. If you change the C3 model, the assembly updates automatically. You insert components, drag them to rough position, then apply constraints (joints) to lock them in place.

F360 Techniques: What's New

New Tools This Lesson

  • 1
    Assembly Environment

    File → New Design, then use the ASSEMBLE tab to insert components

  • 2
    Insert Component

    Browse to the C3 file — it links, not copies. Changes to C3 propagate here automatically.

  • 3
    Move / Free Joint

    Drag the inserted component freely to find a good position before locking it down

  • 4
    Edit Component In Context

    Right-click the deck in the assembly → Edit Component; draw new holes in the deck sketch while seeing where C3 sits; changes propagate to the deck file

  • 5
    As-Built Joint / Rigid Joint

    Constrains C3 to the deck holes so it cannot move relative to the deck

  • 6
    Interference Check

    INSPECT → Interference — checks that no two bodies overlap; run before CNC
