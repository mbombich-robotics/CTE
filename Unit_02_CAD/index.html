Unit 2 — CAD: Component-Based Design

Design and iterate each mechanical component of the L.E.O. robot in Fusion 360. You'll orient to the workspace, model and 3D print your first component, measure it against your design brief, and iterate — the full engineering loop before C2 and beyond. All components converge into a single assembly that passes an interference check before anything goes to CNC.

Grading Levels

Level 1 — C Grade

Replicate the component exactly as specified in the lesson. All dimensions match, sketch fully constrained, assembly passes interference check.

Level 2 — B Grade

Complete Level 1, then apply the modifications described in the component's Activity Guide — altered geometry that still meets functional requirements.

Level 3 — A Grade

Complete Level 2, then redesign one component using the same functional requirements but a different design approach. Justify your choices in the iteration log.
