Component Overview

C2 builds directly on C1 skills. It is the inner structural wheel that presses into the soft silicone tire. The hex bore locks onto the motor's flat-sided shaft — a round bore would spin freely. The spokes exist to reduce weight while keeping the wheel stiff.

Creative Latitude

Spoke design is yours — 3, 5, or 6 spokes; straight or tapered. The only constraint: use Circular Pattern, not individually drawn spokes. This is the one component in the unit where you have real design freedom.

Fusion 360 Techniques

What's New This Lesson

New Tools

  • Polygon tool — inscribed hexagon for the motor shaft bore; set flat-to-flat distance to 3/8″
  • Circular Pattern — select one spoke body or feature, set axis to the central axis, choose count
  • Extrude-Cut — cuts material away to create the open spaces between spokes

Carry-Forward Rules (from C1)

  • Sketch must be fully constrained (all black) before extruding
  • File name: Lastname_DriveWheel_v1-Base
  • Version saves when you print and test fit: v2-HexFit, v2-OD-Fix, etc.
  • Iteration log: record hex bore flat-to-flat as printed vs spec; record OD as printed vs spec; note if silicone tire fit required a reprint
