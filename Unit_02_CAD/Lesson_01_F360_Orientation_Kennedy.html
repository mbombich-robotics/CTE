Know These Terms

You should be able to point to each of these in the F360 interface

Toolbar
Top strip with all the modeling commands (Sketch, Create, Modify…)
Browser
Left panel — lists all Bodies, Components, Sketches in your design tree
Timeline
Bottom strip — every action you take is a step you can go back and edit
ViewCube
Top-right corner — click any face to snap to that view angle
Sketch
2D drawing on a plane — the foundation of every 3D feature
Body
A solid 3D shape — result of extruding, revolving, or other 3D operations
Extrude
Push a 2D sketch shape into the third dimension to create a body
Constraint
A rule that locks sketch geometry — makes dimensions predictable and stable
