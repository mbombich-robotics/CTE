C1 — Wheel Hub

The Wheel Hub is a flanged collar — a flat outer ring (flange) plus a raised central cylinder (hub). It attaches to the omni wheel bearing on the front of L.E.O. The hub must fit precisely: too tight and it won't seat; too loose and the robot wobbles.

New F360 Tools — Lesson 2.1

Tools introduced this lesson

  • Sketch plane — choose XZ plane for the base profile
  • Circle tool — multiple concentric circles, each dimensioned
  • Dimension constraint — click a line or arc, type the value; lines turn black when fully constrained
  • Extrude (multi-depth) — one sketch, two separate Extrude operations for hub height vs. flange thickness
  • Hole tool — 4 bolt holes on a circular pattern
  • Fillet — round the outer flange edge

F360 hygiene — Unit 2 rules

  • Save the file first with correct name, then sketch
  • Constraints before dimensions — fix geometry, then size it
  • Every sketch fully constrained (all lines black) before extruding
  • Version saves: v1-Base, v2-FitFix, v3-WideBore — save a new version each time you print and test
