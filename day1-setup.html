User Experience Program
A screen asks if you want to join Bambu's User Experience Improvement Program. It's optional — you can change it later in Settings.
Click Skip
Step 4 of 11
Printer Selection — Clear All
A grid of Bambu Lab printers appears — they're all checked by default. We only want the printers in our shop, so start by clearing everything.
Click Clear All
Step 5 of 11
Select Class Printers — Bambu Lab
Scroll down to find these three printers and check them. Your screen should match this image when done. Don't click Next yet.
Check Bambu Lab P1S Bambu Lab H2S Bambu Lab P2S
Step 6 of 11
Select Class Printers — Creality
Keep scrolling down past the Bambu printers until you reach the Creality section (the Creality tab will appear highlighted). Find Ender-3 V3 KE in the grid.
Check Creality Ender-3 V3 KE → Click Next
Step 7 of 11
Filament Selection
A long list of filament types appears with many options already selected. The defaults are fine — no changes needed here.
Click Next (keep all defaults)
Step 8 of 11
Bambu Network Plug-in
A screen describes the Bambu Network plug-in — it enables remote control, live streaming, and cloud sync. The install checkbox is already checked.
Click Finish
Step 9 of 11
⚠️ Stop — Admin Approval Needed
A network access dialog will appear asking for permission to connect. This requires admin approval — you can't click past this screen on your own.

Step 10 of 11
Configuration Update
A dialog appears: "A new configuration package available. Do you want to install it?" Accept it to get the latest print profiles.
Click OK
Step 11 of 11
Pin Bambu Studio to Your Taskbar
Bambu Studio is now set up. To make it easy to find every day, pin it to your taskbar — right-click the Bambu Studio icon at the bottom of your screen.
Right-click Bambu Studio icon → Click Pin to taskbar
